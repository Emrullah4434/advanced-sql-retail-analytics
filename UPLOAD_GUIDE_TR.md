# GitHub yükleme rehberi

1. github.com/new sayfasında `advanced-sql-retail-analytics` adında **Public** repository oluştur.
2. **Add README = Off** bırak.
3. `uploading an existing file` bağlantısına bas.
4. Bu klasörün **içindeki** `README.md`, `run_analysis.py`, `.gitignore` ile `sql`, `data`, `docs` klasörlerini yükle.
5. Dosya yolları `sql/02_analysis.sql` gibi görünmeli; başında fazladan `advanced-sql-retail-analytics/` klasörü olmamalı.
6. Commit message: `Initial commit: Advanced SQL Retail Analytics`
7. Profilindeki **Customize your pins** aracından yeni repository'yi sabitle.

Not: `.gitignore` Windows'ta gizli görünebilir. Yüklenmezse de proje çalışır; ancak yerel .sqlite dosyasını GitHub'a yükleme.
